인공지능 (AI)

인간의 지능적 행동을 컴퓨터로 구현하고 시뮬레이션하는 포괄적 분야

🧠

머신러닝 (ML)

명시적 규칙 대신 데이터를 통해 스스로 알고리즘을 구축하는 기술

🕸️

딥러닝 (DL)

인간 뇌를 모방한 인공 신경망을 다층으로 쌓아 올린 고도화 구조

데이터와 보상에 따른 학습 유형

● 지도 학습 (Supervised)

정답(Label)이 포함된 데이터를 활용해 입력-출력 매핑 학습 (예: 이미지 인식)

● 비지도 학습 (Unsupervised)

정답 없이 데이터 내부의 숨겨진 패턴과 구조를 발견 (예: 클러스터링)

● 강화 학습 (Reinforcement)

시행착오와 보상을 통해 최적의 행동 전략을 수립 (예: 게임 AI)

● 준지도 학습 (Semi-supervised)

소량의 라벨 데이터와 대량의 미라벨 데이터를 결합해 학습

인공지능의 역사적 진화

1950s-1960s: 초기 탐색

앨런 튜링의 튜링 테스트 제시, 기호 논리학 중심의 초기 AI 연구 시작.

1980s: 전문가 시스템

특정 분야의 지식을 규칙화한 전문가 시스템 등장, 비즈니스 영역 적용 시도.

2010s: 딥러닝의 부활

빅데이터와 GPU 연산력의 결합으로 신경망 기술이 비약적으로 발전 (AlexNet 등).

2020s: 생성형 혁명

트랜스포머 아키텍처 기반의 초거대 언어 모델과 생성형 AI의 대중화.

📖

트랜스포머 (Transformer)

현대 모든 언어 모델의 표준 아키텍처입니다.

핵심 메커니즘: Self-Attention

문장 내 모든 단어 간의 관계를 동시에 계산하여 맥락을 파악합니다.

$Attention(Q, K, V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$
🎨

확산 모델 (Diffusion)

극사실적 이미지를 생성하는 기술의 핵심입니다.

  • ▶ 전진 과정: 데이터에 노이즈를 단계적으로 추가해 파괴함.
  • ▶ 역과정: 노이즈를 제거하며 원본의 형태를 복원하여 생성함.
[이미지 생성 과정 시뮬레이션: Noise -> Clear Image]
