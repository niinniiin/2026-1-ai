웹 기술의 여정

물리적 신호에서 지능형 공생의 미래까지

인터넷은 어떻게 작동할까요? (OSI 7계층)

L1 - L2

하부 구조

도로와 철로 그 자체. 전기 신호가 흐르는 물리적 통로입니다.

Bit, Frame, MAC 주소
L3 - L4

중추 신경망

전 세계 인터넷 지도. 목적지를 찾고 안전하게 배달합니다.

IP, TCP(신뢰), UDP(속도)
L5 - L6

소통의 규칙

언어 번역과 포장. 데이터를 안전하고 이해 가능하게 만듭니다.

SSL/TLS, JSON, 압축
L7

서비스 최전선

사용자와 마주하는 곳. 실제 웹 서비스가 이루어집니다.

HTTP, DNS, SMTP

웹 세대별 진화 연대기

Web 1.0

정적 정보 소비

  • • Read-Only (읽기 전용)
  • • 단방향 정보 전달
  • • 디지털 잡지 같은 경험
"수동적 소비자"

Web 2.0

참여와 공유

  • • Read-Write (양방향)
  • • SNS, 유튜브, 블로그
  • • AJAX 기술 기반 동적 웹
"플랫폼 중앙화"

Web 3.0

소유와 지능화

  • • Read-Write-Own (소유권)
  • • 블록체인 및 탈중앙화
  • • 시맨틱 웹 (기계가 이해)
"데이터 주권 복구"

Web 4.0

인간과 기술의 공생

  • • Symbiotic Web (공생 웹)
  • • 예측적(Predictive) AI
  • • 초연결 및 맥락 인식
"능동적 파트너 AI"
